# Coffee Orders Excel Analysis

## Project objective

The objective of this project was to analyze coffee order data using Microsoft Excel. The project focused on cleaning and preparing the data, using lookup formulas, creating calculated fields, building PivotTables, and designing a simple dashboard to summarize sales performance.

## Dataset overview

The workbook contains coffee order data with separate sheets for orders, customers, and products. These tables were connected using lookup formulas to create a complete analysis table.

## Workbook sheets

* `orders` — contains the original order records.
* `customers` — contains customer details such as customer name, email, country, and loyalty card information.
* `products` — contains product details such as coffee type, roast type, size, unit price, price per 100g, and profit.
* `Analysis` — contains the cleaned and combined dataset used for analysis.
* `Pivot Tables` — contains summarized results created with PivotTables.
* `Dashboard` — contains the final visual summary of the project.
